# Sourab Das — Performance Marketing Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript. It is ready for free Netlify deployment.

## Files
- `index.html` — page content and SEO metadata
- `styles.css` — responsive dark visual system
- `script.js` — mobile navigation, reveal animations and current year
- `netlify.toml` — static-site publish configuration

## Before publishing (important)
Open `index.html` and replace:
1. `YOUR_EMAIL@example.com` with your real professional email (appears in the contact button and footer).
2. `https://www.linkedin.com/` with your actual LinkedIn profile URL.
3. The certificate placeholders with exact certificate names, issuers, dates and credential links.
4. The Meta Ads case study placeholders with the real client/project, campaign dates, budget, objective and verified metrics. Do not publish invented results.
5. Replace the three illustrative Fivox poster visuals with your actual approved designs if you want to present them as client/brand deliverables. The current page clearly labels them as portfolio-style representations.

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Deploy to Netlify (free)
### Option A — Netlify Drop (quickest)
1. Go to https://app.netlify.com/drop
2. Sign in or create a free Netlify account.
3. Drag the entire unzipped `sourab-performance-marketing-portfolio` folder into the drop area.
4. Netlify will publish it and provide a `*.netlify.app` URL.

### Option B — GitHub connection
1. Create a GitHub repository and upload the contents of this folder (not the outer folder itself).
2. In Netlify, choose **Add new project → Import an existing project**.
3. Connect GitHub and select the repository.
4. Build command: leave blank. Publish directory: `.` (or the repository root).
5. Deploy.

## Editing
You can edit the text directly in `index.html`, and colors/spacing in `styles.css`. After deploying with GitHub, every push to the connected branch can trigger a new deployment.
